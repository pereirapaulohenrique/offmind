Wordmark Variants

Variant A
Precise
Loop sized to match Satoshi Medium's actual "o" proportions. Stroke weight matches stem width. Gap at upper-right — forward movement. Tight kerning to "ff". The typographically correct version.
Variant B
Bold
Satoshi Bold 700. Heavier stroke, more presence. Inspired by "Forest" reference — the modification is bold, geometric, immediately noticeable. Commits fully.
Variant C
Flow
Gap positioned at 3 o'clock (right side). The terminal points toward "ff", creating directional flow from symbol into text. Inspired by "progress" reference — seamless transition.
Variant D
Wide
Wider gap (~120°). The loop becomes a confident "C" shape. Unmistakably "open" — no subtlety. The most conceptually clear version. The gap IS the design.

What changed from v1

  • Stroke weight: 5.5px → 5px (matches Satoshi Medium stem width at 52px)
  • Arc proportions: rx=19/ry=18 → rx=13.5/ry=15.5 (matches Satoshi's actual "o" dimensions)
  • ViewBox: 520 → 280 (tighter, no wasted space, better scaling)
  • Baseline alignment: Arc bottom now sits on y=70 baseline, same as text
  • Kerning: Gap between loop and "ff" tightened (52px → 44px start)
  • Letter-spacing: Reduced from 1 to 0.5 for tighter typography
  • Gap angle: Each variant explores a different gap position for different effects

Recommendation

  • Precise (A) is the safest, most typographically correct choice. The gap at upper-right reads as "forward, upward" — growth.
  • Flow (C) has the best integration — the gap faces right, leading the eye into the text. Most like the "progress" reference.
  • Wide (D) is the boldest statement — if you want "open" to be the first thing people see.
  • Bold (B) trades warmth for authority. Works if OffMind leans more professional.
  • These are still limited by SVG text rendering. Final polish requires converting "ffmind" to paths (traced from the actual font) for pixel-perfect control over the symbol-to-text transition.
